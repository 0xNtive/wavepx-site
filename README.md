# wavepx-site

Website and web app for [wavepx](https://github.com/0xNtive/wavepx) — data over sound.

Built on [ggwave](https://github.com/ggerganov/ggwave) by [Georgi Gerganov](https://github.com/ggerganov).

## Development

```bash
npm install
npm run dev       # start dev server
npm run build     # production build → dist/
npm run preview   # preview production build
```

## Deployment

Deployed to Vercel. Pushes to `main` trigger automatic deploys.
